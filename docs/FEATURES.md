# CarFinder current feature summary

## Active customer features

- Browse vehicles for sale across Zimbabwe.
- Browse rental vehicles with rental period labels.
- Search and filter by keyword, location, price, year, body type, fuel, transmission, import status, mileage, listing type, and verified seller.
- Compare selected cars side by side.
- Save favorites and searches when signed in.
- Contact sellers directly through the available contact flow.
- Submit sale or rental listings after authentication and privacy-policy consent.

## Owner and administrator features

- Supabase-authenticated owner dashboard.
- Separate sale and rental inventory views.
- Owner-scoped edit, pause/mark-sold, and delete actions.
- Admin review workflow and security audit controls.

## Removed from the product

- Blog and blog-post pages.
- AI Match/rules-based matching page.

The route manifest and visible navigation no longer expose those removed features. Existing Terms, Privacy, and Security pages remain available.
